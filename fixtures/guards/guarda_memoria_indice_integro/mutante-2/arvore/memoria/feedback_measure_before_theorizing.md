description: Measure real data before building a theory; a theory from memory is a hypothesis
type: feedback
---
Before explaining a behaviour, collect the data that shows it.

**Why:** twice a plausible theory was written from memory and the first real sample broke it.

**How to apply:** open the log or run the query first; write the theory after, citing the sample.
