## PREMISES

### 1 · Scan before theorizing when the question has a search space
When the question has more than one failure mode, more than one file where the answer can be, or
starts with *"why doesn't this work?"*, a closed-box scan is the FIRST move, not the escalation after
getting stuck. The theory assembles the inputs; it does not replace the sweep.
**Source:** `docs/mapa/1_CONTRATO.md` (Before asking, step 3).

### 2 · What the owner states directs the measurement; it never replaces it
An owner's statement that is right makes a missing check invisible, which makes the habit worse.
Before writing "confirmed" about it, the same proof as for your own claim: the source where the code
decides, and one independent control.
**Source:** `docs/mapa/1_CONTRATO.md` (How I measure).
